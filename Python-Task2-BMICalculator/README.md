# BMI Calculator 🏥

## Project Overview
A simple Python command-line application that calculates Body Mass Index (BMI) using a person's weight and height.

## Features
- Accepts weight in kilograms.
- Accepts height in metres.
- Calculates BMI automatically.
- Classifies BMI into four categories.
- Displays BMI rounded to two decimal places.
- Handles invalid and negative inputs.

## BMI Formula
BMI = Weight (kg) / Height (m)²

## BMI Categories

| BMI Range | Category |
|---|---|
| Below 18.5 | Underweight |
| 18.5 – 24.9 | Normal |
| 25 – 29.9 | Overweight |
| 30 or above | Obese |

## Technologies Used
- Python
- Visual Studio Code

## How to Run

```bash
python bmi_calculator.py
```
